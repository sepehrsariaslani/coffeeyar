# 1. Minimal Design

### فلسفه

حذف هر چیزی که ضروری نیست.

### رنگ‌ها

* سفید
* مشکی
* خاکستری
* یک رنگ Accent

مثال:

```css
#FFFFFF
#111111
#F5F5F5
#2563EB
```

### دکمه‌ها

* گوشه گرد 8 تا 16 پیکسل
* سایه کم
* انیمیشن نرم

```text
[ مشاهده محصولات ]
```

### کارت‌ها

* Border ظریف
* فضای خالی زیاد

### فونت

* Inter
* SF Pro
* Peyda

### ویژگی اصلی

فضای سفید زیاد

# اگر بخواهیم برای سال ۲۰۲۶ یک رتبه‌بندی حرفه‌ای برای سایت‌های تجاری، فروشگاهی، SaaS و برندها بدهیم:

🥇 **Minimal + Bento + Swiss**

* محبوب‌ترین ترکیب دنیا

🥈 **Minimal + Liquid Glass**

* مدرن‌ترین ترند فعلی

🥉 **Scandinavian + Editorial**

* بهترین انتخاب برای مبلمان، دکوراسیون و برندهای لوکس

🏅 **Dark Luxury + Glass**

* مناسب برندهای پریمیوم

🏅 **Immersive 3D + Minimal**

* مناسب برندهای تکنولوژی و AI

برای پروژه مبلمان و دکوراسیونی که قبلاً درباره آن صحبت می‌کردیم، ترکیب **Scandinavian + Minimal + Bento + Swiss Grid** معمولاً بهترین تعادل را بین زیبایی، سرعت، حرفه‌ای بودن و نرخ تبدیل ایجاد می‌کند.
